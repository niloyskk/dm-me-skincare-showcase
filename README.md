# Dm Me Skincare

**A Flutter skincare e-commerce app with AI-assisted skin analysis and product recommendations.**

Independently built by [Md Istain Ahmed](https://www.linkedin.com/in/istain/).

[View on the App Store](https://apps.apple.com/us/app/dm-me-skincare/id6814282967)

## Product overview

Dm Me combines a mobile shopping experience with AI-assisted skincare recommendations.

## Key features

- Product browsing and filtering
- Cart, checkout and order tracking
- OTP authentication and wishlists
- Payments and rewards
- AI-assisted skin analysis and product recommendations

## Technology

**Flutter / Dart · Firebase · Google Gemini API**

## My contribution

I developed the application independently, including the mobile shopping experience, Firebase integration, AI features and store submission.
